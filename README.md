# Star67

[Open Star67 in your browser →](https://learn-sql-peach.vercel.app/)

A guided SQL practice desk for learning practical finance questions. Pick a
question, write a query, run it against a fictional warehouse, and get clear
feedback.

No account, install, upload, API key, paid service, or AI model is required.
Your query and progress stay in your browser.
